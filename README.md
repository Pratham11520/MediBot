# MediBot — Generative AI Medical Assistant

> A portfolio project exploring Retrieval-Augmented Generation (RAG), LLM applications, semantic search, and safety-oriented response workflows.

## What it demonstrates

- Retrieval-Augmented Generation (RAG) over a large medicine dataset
- Semantic search and embeddings
- Multi-LLM application design
- Prompt engineering and deterministic guardrails
- Python/FastAPI backend patterns
- React-based application development

## Related flagship project

The more complete evolution of this work is **MediChain — Multi-LLM Healthcare RAG Platform**, described in my portfolio/resume.

### MediChain highlights

- **254,022** Indian medicine records
- Multi-LLM cascading with provider fallback
- FAISS/vector retrieval
- Contraindication checks and clinical triage workflows
- AES-256 encryption + SHA-256 tamper-evident ledger
- FastAPI + React full-stack deployment
- Reported sub-400ms latency and 99.2% uptime

## Stack

**Python · FastAPI · FAISS · GPT-4 · Gemini · Ollama/LLaMA · React · GCP**

This repository is part of my ongoing exploration of production-oriented GenAI systems, especially RAG, retrieval quality, model orchestration, and application safety.
