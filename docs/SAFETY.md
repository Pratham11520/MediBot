# Safety Notes

MediBot is an AI/software portfolio project and should not be treated as a replacement for a qualified medical professional.

## Application safeguards

- Separate information retrieval from clinical decision-making.
- Make uncertainty visible when source information is incomplete.
- Avoid unsupported medical claims.
- Keep credentials and private data out of logs.
- Apply appropriate access controls when handling health-related information.

Safety requirements should be reviewed again before any real-world deployment.
