# Roadmap

## Retrieval
- Evaluate retrieval precision and recall on a curated test set.
- Add regression tests for high-risk retrieval failures.
- Compare embedding and reranking strategies.

## LLM orchestration
- Track provider latency and failure rates.
- Add structured fallback telemetry.
- Keep model-specific prompts versioned.

## Application quality
- Expand automated tests.
- Add reproducible local setup.
- Document limitations and evaluation methodology.
